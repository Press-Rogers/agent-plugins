<h1 align="center">Press Rogers Agent Plugins</h1>

<p align="center">Human-centred Agent Plugins for Codex.</p>

This public repository is the Git-backed marketplace for Agent Plugins created by Press Rogers. No plugins have been published here yet.

## Add this marketplace to Codex

Open **Plugins**, choose **Add → Add a marketplace**, and enter:

```text
Press-Rogers/agent-plugins
```

The marketplace catalog lives at `.agents/plugins/marketplace.json`. Individual plugins will be added under `plugins/` as they are created.
